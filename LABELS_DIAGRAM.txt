STEP 5: MERGE TASK WITH FOLLOWING REST
════════════════════════════════════════

(Rationale: subjects keep imagining during rest, task-related signal persists)

    + following rest (Block 3): TR 48-60

    + following rest: TR 95-110
    = combined: TR 60-110


STEP 6: APPLY TRIM_START = 2 TRs
═════════════════════════════════

Remove first 2 TRs (~1.6 seconds) to drop pre-task activity

tennis:    TR 10-60  →  trim 2  →  [12, 60)     = 48 TRs
navigation: TR 60-110 →  trim 2  →  [62, 110)    = 48 TRs

                = 48 - 32 + 1 = 17 windows, all label='navigation'

Plus windows from 'squeeze' blocks (~17 windows each)
